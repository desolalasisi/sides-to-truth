- Sides to Truth

An interactive memory game created as part of an upcoming art series.

This game explores themes of perception, perspective, and the different "sides" of truth through a collection of visual artworks. Players are invited to engage with the images in a playful way while discovering elements from the larger project.

- About the Project

The artworks featured in this game are part of a new series launching soon - 20/06/26. Each image represents a different aspect of the broader narrative and themes explored in the collection.
